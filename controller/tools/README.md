# Tools

NirSoft utilities used for Windows control. They are not committed (NirSoft's
licence asks for the full zip when redistributing), so download them here:

| File | From |
|---|---|
| `svcl.exe` | https://www.nirsoft.net/utils/svcl-x64.zip (SoundVolumeCommandLine, 64-bit) |
| `MultiMonitorTool.exe` | https://www.nirsoft.net/utils/multimonitortool-x64.zip (64-bit) |

Unzip and copy just the `.exe` into this folder.

`config/monitors-extend.cfg` was made with `tools\MultiMonitorTool.exe /SaveConfig config\monitors-extend.cfg`
while both monitors were on in the normal layout. Re-run that if the layout changes.
